# 凭据中心

入口：资产与工具 → 凭据中心。凭据按项目隔离，统一保存操作系统、数据库、网络与安全设备、应用与服务及其他凭据。类型可自定义，数据库内置 40 种常见产品。平台不提供专用 SSH / WinRM 连接器或终端，也不会在导入时连接目标。

## 状态与验证

新增、导入凭据默认为“未验证”。有两种方式变为“可用”：

- 用户选中记录，通过“批量操作 → 标记选中为可用”确认，记录来源为“用户确认”。单条记录也可在更多菜单中确认。
- 用户选中记录，点击“交给 Agent 验证”。平台会在当前项目新建独立的普通对话，启用凭据工具并发送验证任务，Agent 按类型选择方式，使用正常命令工具、项目容器和既有审批规则执行验证，再上报成功或失败。原对话的运行或压缩不会被打断，也不会阻止新建验证对话。无法确认时应保持原状态。

勾选对话中的“凭据中心”即允许 Agent 主动读取、验证并上报当前项目内凭据，无需用户逐条选择。未验证或验证失败的凭据可直接读取用于验证，上报成功后再用于其他任务；可用凭据可以按需读取并用于任务。工具只限制凭据读取范围和状态，实际验证结论由 Agent 上报，并非独立验证器的证明。

对话输入区的 iOS 旁有“凭据中心”开关，默认关闭，只作用于当前对话，随会话保存。开启后允许 Agent 结合对话任务主动管理、验证并提交结果，无需再从凭据页面授权；开关本身不发送任务消息，也不注入密码。关闭会清除该对话已读取的验证版本，再次开启后需要重新读取才能上报。工程和子 Agent 不自动继承凭据工具。

修改目标、类型、账号、认证信息、数据库 / 实例或自定义字段后，会生成新的凭据版本并恢复“未验证”；只修改名称和备注保留状态。验证结果绑定所读取的凭据版本和本次会话授权，旧结果不能覆盖新版本，也不能覆盖之后的用户确认。

验证记录保存方式、简短结论、时间、来源、来源会话及凭据版本；不归档原始请求响应或命令输出。历史记录保留，页面会标出历史版本。已知密码、密钥、Token 和敏感自定义字段会在验证结论中脱敏；请勿提交业务数据。

## 字段与批量导入

建议优先在“对话”中勾选“凭据中心”，直接粘贴凭据或上传文件，让 AI 识别类型、整理字段并逐条或批量保存。手动添加和批量导入窗口也提供这一提示。

同时支持 CSV / JSON 文件上传或粘贴，页面可下载模板。每批 1–1000 条，最多 2 MB，先校验并预览，再确认导入。任一条格式错误拒绝整批。同批重复记录也会拒绝。

去重键为“类型 + 目标地址 + 端口 + 用户名 + 数据库名 + 实例名”。相同记录更新，空白密码、私钥、私钥口令、Token 或敏感自定义字段保留已有值；未提供 `fields` 时保留现有自定义字段，显式提供数组则替换字段集合。不同数据库或实例保留为不同凭据。预览后项目凭据发生变化，需要重新预览。

| 字段 | 含义 |
| --- | --- |
| `name` | 显示名称，默认使用目标地址 |
| `group` | 操作系统、数据库、网络与安全设备、应用与服务、其他；内置类型自动推断 |
| `type` | 必填，内置产品名或自定义类型名 |
| `host` | 必填，IP、域名或服务地址，不要包含密码 |
| `port` | 可选，1–65535；空值不推断协议 |
| `username` | 账号，可选，例如 Token 认证时可以留空 |
| `password` / `privateKey` / `passphrase` / `token` | 敏感认证信息，按需填写 |
| `database` / `instance` / `domain` | 数据库、实例及域 |
| `manufacturer` / `model` | 厂商与型号 |
| `notes` | 备注，不能用于保存密码或业务数据 |
| `fields` | 扩展字段数组，每项为 `{"key":"名称","value":"值","sensitive":true}` |

JSON 示例（仅示例凭据）：

```json
[
  {
    "name": "业务只读数据库",
    "type": "PostgreSQL",
    "host": "192.0.2.10",
    "port": 5432,
    "username": "operator",
    "password": "replace-me",
    "database": "app",
    "fields": [{"key": "sslmode", "value": "require", "sensitive": false}]
  },
  {"type": "内部设备", "group": "其他", "host": "192.0.2.20", "token": "replace-me"}
]
```

CSV 第一行为字段名。逗号、引号或换行使用双引号包裹，字段内部引号写成两个引号。私钥支持多行字段；`fields` 列填写经 CSV 转义的 JSON 数组，下载模板内有示例。

## Agent 工具

工具固定绑定会话所属项目，不能通过参数切换项目，即使后台运行或用户切换项目也不改变归属。

| 工具 | 行为 |
| --- | --- |
| `credential_list` | 搜索、分页列出脱敏记录 |
| `credential_read` | 指定 ID 按需取明文；`purpose=verify` 允许验证项目内任意凭据，`purpose=use` 仅允许可用凭据 |
| `credential_save` | 保存发现的凭据，或携带 ID、当前 `revision` 更新；不能设置可用状态 |
| `credential_report_validation` | 对当前对话已读取验证的版本上报结果、方式和简短结论 |

## 容器客户端与工具指引

勾选“凭据中心”后，当前对话的系统提示词会同步加载客户端选择及验证流程指引；取消勾选后移除。点击“交给 Agent 验证”创建的新对话也会加载。Agent 优先通过项目容器内现成客户端完成最小认证检查，只有工具无法满足目标认证方式时才补充驱动调用，避免每次新建项目都编写连接代码。

| 类型 / 协议 | 优先工具 |
| --- | --- |
| Linux、Unix、macOS、设备 SSH | `ssh`；密码配合 `sshpass -e`，私钥用 `ssh -i` |
| Windows WinRM / SMB / SSH | 按实际协议选 `nxc winrm`、`nxc smb`、`ssh` |
| LDAP / Active Directory | `ldapwhoami`、`ldapsearch` |
| MySQL / MariaDB 及兼容数据库 | `mariadb` |
| PostgreSQL 及兼容数据库 | `psql` |
| Redis | `redis-cli` |
| SQL Server / Sybase TDS | `tsql`；SQL Server 也可用 `impacket-mssqlclient` |
| SQLite 本地文件 | `sqlite3` |
| MongoDB | 系统 `python3` 的 `pymongo.MongoClient`，使用认证配置执行 `ping` |
| SNMP 设备 | `snmpget` |
| HTTP API、Elasticsearch / OpenSearch、ClickHouse、InfluxDB、CouchDB | `curl` |

工具镜像新增 `sshpass`、`ldap-utils`、`mariadb-client-core`、`postgresql-client`、`redis-tools`、`sqlite3`、`freetds-bin`、`snmp`、`python3-pymongo`、`python3-dnspython`，复用已有 SSH、curl、NetExec 和 Impacket。安装使用 `--no-install-recommends`，不安装数据库服务端、桌面客户端或 mongosh。本地 ARM64 构建实测新增镜像层约 65.5 MB（APT 预估新增安装体积约 59 MB），实际大小随架构、基础镜像和 Kali 软件源版本变化。

更新后需在“设置 → 环境”重新构建工具镜像；新项目使用更新后的镜像，已有项目需通过项目容器重建操作切换到新镜像，单纯重启容器不会新增工具。客户端层位于 Dockerfile 末尾，可复用已有构建缓存。

提示词要求先检查工具和参数、使用凭据中的实际端口与认证配置、设置超时，并执行最小认证查询。端口开放、HTTP 200 或匿名访问不能证明凭据有效；缺少工具、网络异常或 TLS / 协议不匹配时保留原状态并说明原因。客户端通过环境变量或受限临时文件接收敏感信息，验证后清理临时文件。类型目录支持的产品多于预装客户端范围，其他类型按实际协议复用工具或按需补装。

## 清理与存储

支持单条删除、勾选删除及清理当前项目所有“验证失败”的记录，清理前显示数量并确认。确认期间失败集合发生变化需重新确认。删除凭据会删除其验证历史；删除项目数据时同步清理该项目凭据。

控制台数据目录（通常为 `~/.sentinel/agent`）中的 `credentials.db` 使用 AES-256-GCM 加密每条完整记录，独立密钥为 `credentials.key`，文件权限为 `0600`。备份与恢复需同时保存两者；缺少密钥时拒绝打开已有库。

列表、编辑表单和导入预览不回传密码、密钥、Token 或敏感自定义字段值。Agent 显式调用读取工具后，明文会进入模型上下文及会话工具记录，可能发送至配置的模型服务。验证命令也可能产生目标侧日志或对话工具输出；这与凭据库仅保存简短验证记录是不同的存储边界。只在需要的对话中启用工具，并使用适合当前项目的数据与模型配置。
