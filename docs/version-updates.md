# 版本检测

登录控制台后，浏览器会查询官方 GitHub 仓库的最新正式 Release，仅比较版本号。发现新版本时，侧栏底部显示更新图标；「关于」页显示最新版本，并提供「检查更新」和发布页入口。

- 检测结果在浏览器缓存 6 小时，打开页面和恢复可见时按缓存期限检查；持续打开的页面也会定期检查。「检查更新」可立即重新检测。
- 比较按主版本、次版本、补丁号进行，不按字符串排序；相同版本、旧版本、草稿和预发布版本不会触发升级提示。
- 只读取官方 `releases/latest` 的版本信息，不下载更新包、不运行更新脚本、不覆盖安装文件，也不发送项目、目标、会话或登录信息。
- 需要浏览器能够访问 GitHub API；网络失败、限流或尚无正式 Release 时，「关于」页会显示无法完成检测，不会误报「已是最新版本」。

维护者发布时请在官方仓库创建正式 Release，Tag 使用 `v2.2.12` 或 `2.2.12` 这样的版本号。用户通过发布页按现有部署方式手动更新。
