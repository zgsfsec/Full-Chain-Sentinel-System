---
id: database-access-check
name: 数据库访问控制检查
category: 数据安全/访问控制,数据库安全
description: 根据实际数据库检查认证、授权与连接保护配置
---

仅对操作员指定的数据库和实例进行低影响安全检查。先确认产品类型、版本、实例或数据库名、连接协议、账号权限和检查范围。

按需使用凭据中心，并先实际验证未确认的凭据。优先使用容器内已有客户端和只读系统目录查询，不编写重复连接代码；设置有限超时。

检查认证设置、匿名或默认访问、当前可见角色与权限、最小权限落实情况及连接加密配置。不枚举或导出业务表数据，不修改用户、角色、配置或数据，不进行口令猜测及高负载测试。

根据产品差异自主组织检查。将配置事实与风险判断分开，无法观察的配置明确说明，不能凭端口开放或客户端缺失认定安全问题。报告给出范围、判断依据、问题和整改建议，隐去认证秘密及业务数据；不声称覆盖完整数据安全合规标准。
