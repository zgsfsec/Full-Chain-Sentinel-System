对操作员指定的 Linux 主机开展只读账号安全检查。

先确认目标系统、当前账号权限、可用工具及本轮范围。使用凭据中心时，未验证或验证失败的凭据先执行最小认证检查并上报，成功后再用于检查。

结合实际系统检查账号状态、异常或闲置高权限账号、密码策略、SSH 认证配置和 sudo 授权。自行选择适用的命令及配置文件，避免读取密码哈希或导出认证秘密，不修改账号、口令、权限和业务配置。

针对有证据的问题说明实际配置、影响及整改建议；区分已确认、不适用、无权读取和无法检查。报告不包含密码、私钥、Token 或完整业务数据。

本规则是检查示例，不代表完整的等保测评标准或合规认证。最终通过普通工程报告流程交付结果。
